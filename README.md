# Pop Cat ทีม (Node.js + Render.com — ฟรี)

เกมกดแมวแข่งเป็นทีมแบบเรียลไทม์ เซิร์ฟเวอร์เขียนด้วย Node.js ล้วนๆ (ไม่มี
dependency ภายนอก) รันฟรีบน Render.com เพื่อนแค่เปิดลิงก์ก็เล่นได้ทันที
ไม่ต้องมีบัญชีหรือ log in ใดๆ ทั้งสิ้น

## ภาพรวมขั้นตอน
1. เอาโค้ดนี้ขึ้น GitHub (เก็บไว้เป็น repository ของคุณ)
2. เชื่อม GitHub นั้นกับ Render.com แล้วให้ Render deploy ให้อัตโนมัติ
3. ได้ลิงก์ `https://ชื่อที่ตั้ง.onrender.com` ส่งให้เพื่อนเล่นได้เลย

---

## ขั้นตอนที่ 1: อัปโค้ดขึ้น GitHub

1. สมัคร/ล็อกอิน GitHub ที่ https://github.com
2. กดปุ่ม **New** (สร้าง repository ใหม่) มุมขวาบนหรือที่หน้า https://github.com/new
   - ตั้งชื่อ เช่น `popcat-teams`
   - เลือก **Private** หรือ **Public** ก็ได้ (ไม่มีข้อมูลลับในโค้ดนี้)
   - **ไม่ต้อง** ติ๊ก "Add a README" (มีอยู่แล้วในไฟล์นี้)
   - กด **Create repository**
3. หน้าที่ได้จะมีคำสั่งให้ก็อปวาง ให้เลือกวิธีที่ง่ายที่สุด: **อัปโหลดไฟล์ผ่านเว็บ**
   - หน้า repository ที่สร้างใหม่ จะมีลิงก์ "uploading an existing file" ให้กด
   - ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (`server.js`, `package.json`, `README.md`, `.gitignore`
     และโฟลเดอร์ `public` ทั้งโฟลเดอร์ พร้อม `public/index.html` ข้างใน) ไปวางในหน้านั้น
   - เลื่อนลงล่าง กด **Commit changes**

   (ถ้าถนัดใช้คำสั่ง git ในเครื่องมากกว่า ก็ใช้ `git init`, `git add .`,
   `git commit -m "init"`, `git remote add origin <ลิงก์ repo>`, `git push -u origin main`
   ได้เช่นกัน)

## ขั้นตอนที่ 2: Deploy บน Render.com

1. สมัคร/ล็อกอิน Render ที่ https://dashboard.render.com/register (สมัครด้วยบัญชี GitHub ได้เลย จะเชื่อมง่ายขึ้น)
2. ที่หน้า Dashboard กด **New +** > **Web Service**
3. เลือก **Build and deploy from a Git repository** แล้วกด **Next**
4. ให้สิทธิ์ Render เข้าถึง GitHub ของคุณ แล้วเลือก repository `popcat-teams` ที่สร้างไว้
5. กรอกค่าตั้งค่า:
   - **Name:** ตั้งชื่อที่ต้องการ (จะกลายเป็นส่วนหนึ่งของลิงก์ เช่น `popcat-teams` → `popcat-teams.onrender.com`)
   - **Region:** เลือกที่ใกล้ผู้เล่นส่วนใหญ่ (เช่น Singapore ถ้าเพื่อนอยู่ไทย)
   - **Branch:** `main`
   - **Runtime:** Node
   - **Build Command:** ปล่อยว่างไว้ได้ (ไม่มี dependency ให้ติดตั้ง) หรือใส่ `npm install` ก็ได้เช่นกัน
   - **Start Command:** `node server.js`
   - **Instance Type:** เลือก **Free**
6. กด **Deploy Web Service** แล้วรอสัก 1-2 นาที ดู log จนขึ้นว่า `listening on <port>`
7. ลิงก์เกมจะอยู่ด้านบนของหน้า ประมาณ `https://popcat-teams.onrender.com` — ส่งให้เพื่อนเปิดได้เลย

## ข้อควรรู้เรื่องแพ็กเกจฟรีของ Render

- เซิร์ฟเวอร์ฟรีจะ **หลับ** เมื่อไม่มีคนเข้าใช้ประมาณ 15 นาที ครั้งแรกที่เปิดหลังหลับจะ
  ใช้เวลาโหลดหน้าเว็บช้ากว่าปกติ ~30-60 วินาที เพราะเซิร์ฟเวอร์กำลังตื่น แนะนำให้
  Host **เปิดลิงก์รอไว้ล่วงหน้าสัก 1 นาที** ก่อนเริ่มเล่นจริง
- คะแนนและห้องทั้งหมดเก็บไว้ใน **หน่วยความจำของเซิร์ฟเวอร์** เท่านั้น ถ้าเซิร์ฟเวอร์
  รีสตาร์ทหรือหลับกลางเกม ห้องจะหายไป จึงควรเล่นให้จบในรอบเดียวไม่ทิ้งช่วงนานเกิน 15 นาที
- โควตาฟรีของ Render อาจเปลี่ยนแปลงได้ ดูรายละเอียดล่าสุดที่ https://render.com/pricing
- **สร้างห้องแล้วรีบให้เพื่อนกดเข้าห้องภายในไม่กี่นาที** อย่าเว้นช่วงนาน เพราะถ้าเซิร์ฟเวอร์หลับไปแล้วตื่นใหม่ ห้องเดิมจะหายไปเลย (ต้องสร้างห้องใหม่)

## อัปเดตโค้ดในอนาคต

แก้ไฟล์แล้วอัปขึ้น GitHub repo เดิม (อัปโหลดทับผ่านเว็บ หรือ `git push`) — Render จะ
deploy เวอร์ชันใหม่ให้อัตโนมัติทุกครั้งที่มีการ push เข้า branch `main`

## ทดสอบในเครื่องตัวเอง (ไม่บังคับ)

```
node server.js
```
แล้วเปิด http://localhost:3000 (เปิดหลายแท็บเพื่อจำลองหลายคน)

## วิธีเล่น

- Host: เปิดลิงก์ > สร้างห้อง > ตั้งจำนวนทีมและชื่อทีม > ส่งรหัสห้อง 4 ตัวให้เพื่อน >
  เลือกเวลา 1/3/5/10 นาที > กดเริ่ม
- ผู้เล่น: เปิดลิงก์ > ใส่รหัสห้อง > ใส่ชื่อ > แตะทีม > รอ Host เริ่ม
- Host ยกเลิกห้องได้ทุกเมื่อ (แตะปุ่มยกเลิก 2 ครั้งเพื่อยืนยัน) ผู้เล่นจะถูกพากลับหน้าแรก
- จบเกมแล้ว Host กด "เล่นอีกรอบ" ได้ ผู้เล่นและทีมเดิมอยู่ครบ คะแนนรีเซ็ต
